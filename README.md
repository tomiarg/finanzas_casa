# Casa — Finanzas 🏠

App de finanzas del hogar, pensada para usar desde el celu.

## Cómo deployar en Railway

1. Subí esta carpeta a un repo de GitHub (puede ser privado)
2. En Railway: New Project → Deploy from GitHub repo → elegís el repo
3. Railway detecta el `package.json` y hace todo solo
4. En 2 minutos tenés la URL

## Cómo instalarla en el celu (iOS y Android)

**iPhone:**
- Abrís la URL en Safari
- Tocás el botón de compartir (cuadradito con flecha)
- "Añadir a pantalla de inicio"
- Listo, aparece como app

**Android:**
- Abrís la URL en Chrome
- Menú → "Añadir a pantalla de inicio"
- Listo

## Compartir con tu señora
Solo compartile la URL de Railway. Los dos ven los mismos datos porque se guardan en el mismo dispositivo por localStorage — si quieren sincronización real entre dispositivos, avisame y lo conecto a una base de datos.
